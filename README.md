# Fainting-Spell
## Game Overview:
Fast paced FPS shooter, where player uses spells as weapons

Link to project: https://rostyslav2176.itch.io/fainting-spells

## How to Play:
 WASD - Movement

 Mouse - Rotate

 Left Mouse Button - Shoot

 Shift - Sprint

 Ctrl - Crouch

 Space - Jump

## How to run the application:
### Github Installation
  1. Make sure you have Unity 2022.3.11f installed or are comfortable with version upgrading
  2. Download Zip
  3. Extract file to desired location
  4. Open extracted folder in Unity
